Gardener Pass 最初在 [seasons](https://garden.finance/zh/blog/seasons-intro) 计划中推出，现在可通过永久质押 21,000 枚 SEED 来铸造。每枚 Pass 都为持有者提供生态系统内一系列专属权益与机会：

<CardGroup cols={1}>
  <Card title="永久质押加成系数" icon="chart-line">
    Pass 持有者的质押奖励可获得 7 倍加成系数。
  </Card>
  <Card title="更强的治理权" icon="users-gear">
    质押 21,000 枚 SEED 通常可获得 10 票治理投票权。而 Gardener Pass 持有者凭借 7 倍加成系数可获得 70 票，在协议治理和收益分成中拥有相当大的影响力。
  </Card>
  <Card title="可交易性" icon="arrows-rotate">
    作为一种完全可交易的 NFT，Pass 可以在[交易市场](https://opensea.io/collection/gardener-pass)上出售或转让。铸造 Pass 需要永久质押 SEED，这实际上等同于销毁这些 SEED，由此确立了 Pass 的内在价值。
  </Card>
</CardGroup>

<Note>
你可以在[质押页面](https://app.garden.finance/zh/stake)无限期质押 **21,000 枚 SEED** 来铸造 Gardener Pass。
</Note>

## 下一步是什么？

随着我们迈入 Act 2，Pass 不再只是一项功能，而是真正参与 Garden 发展历程的一种方式。持有 Pass，你将获得**新功能抢先体验**以及**更深入参与的机会**，与我们共同建设。

质押 SEED 获取 Pass 不只是为了治理权或质押奖励，更是为了与 Garden 的成长和长期愿景保持一致。这个生态系统归社区所有，而 Pass 是每一位准备挺身而出、帮助引领其方向的人的**成人礼**。
