---
title: "Проверка адресов"
description: "Обзор процесса мониторинга рисков в Garden"
---

Garden — не требующий разрешений протокол для одноранговых обменов Bitcoin и других активов через сеть солверов. Протокол не хранит средства пользователей, и любой желающий может участвовать в нём в качестве солвера.

Garden использует API проверки от **TRM Labs, ZeroShadow, Bybit** и **Binance**, чтобы поддерживать ответственное использование протокола и не допускать взаимодействия с ним субъектов, находящихся под санкциями.

- Адреса кошельков, подключаемых к интерфейсу Garden, автоматически проверяются через интегрированные API.
- Если адрес определён как находящийся под санкциями, функция обмена отключается.
- Если обмен включает депозит в Bitcoin, проверяется и адрес, с которого вносятся средства. Если он помечен, солверы получают сигнал не инициировать обмен. При этом пользователь может вернуть свой Bitcoin после истечения срока обмена.
- Ордера, отправленные через сторонние интеграции с использованием SDK или API Garden, проходят такую же проверку.
